# まなびログ 📖 – 学習記録アプリ

生徒が毎日の学習をかんたんに記録できるWebアプリです。
ビルド不要・サーバー不要で、ブラウザだけで動きます。

## 機能

- **学習の記録** — 日付・教科・学習内容・学習時間・理解度(5段階の顔アイコン)・ふりかえりメモを記録
- **ホーム(ダッシュボード)**
  - 今日の学習時間 / 今週の合計 / 連続記録日数
  - 直近7日間の学習時間グラフ(1日の目標ラインつき)
  - 今週の教科別学習時間の内訳
- **記録の一覧** — 日付ごとにまとめて表示。教科・期間でしぼりこみ、編集・削除
- **設定**
  - 教科の追加・削除(色は自動で割り当て)
  - 1日の目標学習時間の設定
  - データの書き出し・読み込み(JSON)— 端末をかえるときのひっこし用
- スマホ対応(下タブのナビゲーション)・ダークモード対応

## データの保存について

記録はブラウザの `localStorage` に保存されます。サーバーには何も送信されません。
端末やブラウザをかえるときは「設定 → データを書き出す / 読み込む」を使ってください。

## 使い方(ローカルで開く)

`index.html` をブラウザで開くだけで動きます。ローカルサーバーを使う場合:

```bash
npx serve .
# または
python3 -m http.server 8000
```

## Firebase Hosting で公開する

`firebase.json` を同梱しています。

```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # 既存のFirebaseプロジェクトを選択(公開ディレクトリは「.」)
firebase deploy
```

## ファイル構成

```
index.html   … 画面(ホーム / 記録する / 一覧 / 設定)
style.css    … スタイル(ライト/ダークのカラートークン)
app.js       … ロジック(記録の保存・集計・グラフ描画)
firebase.json… Firebase Hosting 設定
```

## 今後の拡張アイデア
