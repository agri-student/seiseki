# Seiseki 📊 – 成績管理・学習支援アプリ(農業高校向け)

生徒が学習の記録・成績の管理・弱点の克服をひとつでできるWebアプリです。
**ローカルモード(サーバー不要)** をベースに、**Firebase連携(ログイン・複数端末の同期)** と
**個人APIキーによるAI問題生成(BYOK)** を任意で追加できます。PWA対応でスマホのホーム画面に追加して使えます。

## 画面構成(6タブ)

| タブ | 機能 |
|---|---|
| 🏠 **ホーム** | 今週の勉強時間・次の提出物・目標達成率/進路アドバイス/得意・不得意レーダー/成績推移グラフ |
| ⏱️ **学習** | 学習タイマー/学習記録/提出物・課題(検定日などの期限管理にも) |
| 📚 **プリント** | プリント・資料を科目ごとに保存(画像・PDF)/**AIで問題をつくる**/**保存ずみ問題セット**(何度でも解きなおせる) |
| 📕 **弱点** | 弱点ノート/**フラッシュカードで復習**/**鑑定カード(写真で暗記・農業鑑定競技対策)** |
| 👥 **フレンド** | フレンドコード/勉強時間ランキング |
| ⚙️ **設定** | 学校・学年・科目/進路目標/週の目標時間/**自分のAIキー(BYOK)**/アカウント(同期)/データ書き出し |

## AI問題生成のしくみ(個人キー方式・BYOK)

AI問題生成は**生徒が自分で用意したAPIキー**で動きます(学校側のAIサーバー・API契約は不要です)。

- 対応: **OpenAI(ChatGPT)/ Anthropic(Claude)/ Google(Gemini)**。モデル名も変更可(空欄で標準)
- キーは「設定 → 自分のAIキーで問題をつくる」に登録。**その端末のlocalStorageにだけ**保存され、
  クラウド同期・JSON書き出しには含まれません
- 生成した問題セットは自動保存され、**2回目からはAI利用料なし**で何度でも解きなおせます
- まちがえた問題は弱点ノートへ自動保存 → フラッシュカードで復習できます
- OpenAIは画像のみ対応(PDF不可)。Claude/GeminiはPDFも可
- 出題専用プロンプト+JSON強制でプロンプトインジェクション・形式崩れを抑止。
  「AIが作った問題はまちがっていることがあります」を常時表示

**運用上の注意(教員向け):**
- 各社のAPIアカウント作成には年齢条件(多くは18歳以上)があります。実運用は**保護者名義または学校名義のキー**を配る形を想定してください
- キーには各社コンソールで**月額上限**を必ず設定させてください
- 共用PCにはキーを保存しない(使い終わったら「キーを削除」)。端末を触れる人はキーを取り出せる方式です

## Q. データを貯めるのにFirebaseは必須?

**必須ではありません。** ローカルモードでも記録・成績・弱点・問題セット・鑑定カードはブラウザ
(localStorage/IndexedDB)に蓄積され、JSON書き出しでバックアップできます。
Firebaseを設定すると **ログイン/複数端末の同期/ブラウザデータ消去への耐性** が加わります。
AI問題生成はBYOK方式なので、**FirebaseがなくてもAIは使えます**。

## 使い方(ローカルモード)

```bash
npx serve .
# または
python3 -m http.server 8000
```

PWAなので、スマホのブラウザで開いて「ホーム画面に追加」するとアプリとして使えます(2回目以降はオフラインでも起動)。

## Firebase連携のセットアップ(教員向け・任意)

Cloud Functionsを使わないため、**無料のSparkプランで運用できます**
(プリント実ファイルの端末間同期に使うStorageのみ、新規プロジェクトではBlazeプランが必要な場合があります。
Storageが無くても、プリントはアップロードした端末内でそのまま使えます)。

1. [Firebaseコンソール](https://console.firebase.google.com/)でプロジェクト作成
2. **Authentication** → 「メール/パスワード」を有効化(必要なら「Google」も)
3. **Firestore Database**(と可能なら **Storage**)を作成
4. プロジェクトの設定 → ウェブアプリを追加 → 構成をコピー
5. `firebase-config.example.js` を `firebase-config.js` にコピーして構成を貼りつけ
6. ルールとHostingのデプロイ:

```bash
npm install -g firebase-tools
firebase login && firebase use <プロジェクトID>
firebase deploy
```

## セキュリティ設計

- Firestore/Storageルールで「**自分のデータしか読み書きできない**」を強制(`firestore.rules` / `storage.rules`)
- Storageルール側でも20MB以下・画像/PDFのみを強制
- AIキーはサーバー・クラウドに送られない(各生徒の端末 → AI各社への直接通信のみ)
- APIに送るのはプリントの中身だけで、氏名・成績などの個人情報は送らない設計

## ファイル構成

```
index.html    … 画面(6タブ+成績/AIクイズ/フラッシュカードモーダル)
style.css     … スタイル
app.js        … アプリ本体(ローカルで完結して動く)
byok.js       … 個人APIキーでのAI問題生成(OpenAI/Claude/Gemini)
cloud.js      … Firebase連携(firebase-config.jsがあるときだけ有効)
sw.js / manifest.json / icons/ … PWA(ホーム画面追加・オフライン)
firebase-config.example.js … Firebase設定の見本
firebase.json / firestore.rules / storage.rules … Firebase設定
```
