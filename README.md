# Seiseki 📊 – 成績管理・学習支援アプリ

生徒が学習の記録・成績の管理・弱点の克服をひとつでできるWebアプリです。
ビルド不要・サーバー不要で、ブラウザだけで動きます。

## 画面構成(6タブ)

| タブ | 機能 |
|---|---|
| 🏠 **ホーム** | 今週の勉強時間・次の提出物・目標達成率のタイル/進路アドバイス/得意・不得意レーダー/科目ごとの成績推移(得点率)グラフ/成績の追加 |
| ⏱️ **学習** | 学習タイマー(秒単位で自動記録)/手動の学習記録(内容・時間・理解度・ふりかえり)/提出物・課題の管理/学習の記録一覧 |
| 📚 **プリント** | 授業プリント・資料を科目ごとに保存(画像・PDF / 最大20MB、IndexedDBに保存)/開く・削除 |
| 📕 **弱点** | 弱点ノート:間違えた問題・ニガテなことを保存して「克服した!」でチェック |
| 👥 **フレンド** | フレンドコードの表示・コピー/今週の勉強時間ランキング(月曜始まり) |
| ⚙️ **設定** | 表示名/学校(小・中・高)・学年・科目の管理/進路目標/週の目標勉強時間/提出物の通知/データの書き出し・読み込み |

## データの保存について

- 記録・成績・設定はブラウザの `localStorage`、プリントのファイル本体は `IndexedDB` に保存されます。サーバーには何も送信されません。
- 端末やブラウザをかえるときは「設定 → データを書き出す / 読み込む」を使ってください(プリントのファイル本体は書き出しに含まれません)。

## オンライン版で追加できる機能(今後の拡張)

現在はサーバー不要のローカル版です。Firebase(Authentication / Firestore / Storage)と
AI APIをつなぐと、次が実現できます。

- ログイン(学校アカウント)と複数端末の同期
- フレンド申請・フレンドどうしの勉強時間ランキング
- プリントの「AIで問題をつくる」(資料を参照した選択+記述の模擬問題生成)と、
  間違えた問題の弱点ノートへの自動保存
- AIによる進路アドバイス(現在は端末内の記録から生成する簡易アドバイス)
- プッシュ通知での提出物リマインド(現在はアプリを開いたときに通知)

## 使い方(ローカルで開く)

`index.html` をブラウザで開くだけで動きます。ローカルサーバーを使う場合:

```bash
npx serve .
# または
python3 -m http.server 8000
```

## Firebase Hosting で公開する

`firebase.json` を同梱しています。

```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # 既存のFirebaseプロジェクトを選択(公開ディレクトリは「.」)
firebase deploy
```

## ファイル構成

```
index.html   … 画面(ホーム / 学習 / プリント / 弱点 / フレンド / 設定)
style.css    … スタイル(ライトブルー基調のカラートークン)
app.js       … ロジック(記録・成績・グラフ・タイマー・保存)
firebase.json… Firebase Hosting 設定
```
